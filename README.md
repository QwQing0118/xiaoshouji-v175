## 怎么跑

没有任何依赖，浏览器直接开就行：

```bash
# 方式一：直接双击 / 浏览器打开 index.html（部分浏览器 file:// 会限 localStorage，建议用方式二）

# 方式二：起个静态服务（推荐）
cd 这个目录
python3 -m http.server 8792
# 然后浏览器打开 http://127.0.0.1:8792/
```

手机上实测可用的打开方式：

```bash
am start -a android.intent.action.VIEW -d 'http://127.0.0.1:8792/' -t 'text/html'
```

## 数据说明

- 所有数据都在浏览器的 `localStorage` 里，**没有数据库、没有后端、没有账号**。
- 清浏览器缓存 = 数据全没。想保住就先导出一份。
- 换浏览器或换设备不会同步，各自独立。

## ⚠️ 接手须知（重点）

1. **`fetch(` 出现 0 次** —— 这一版完全没有后端依赖，别照着 V2 的思路去找 `/api/` 接口，这里一个都没有。
2. **单文件 616 KB** —— 全部 HTML/CSS/JS 都在这一个文件里，改的时候注意别把 JS 语法改崩（V2 踩过这个坑，改完务必做语法自检）。
3. **`__SC` 花体字映射** —— 从 V1 App 版继承过来的，是应用名/标题的美化映射表。
4. **强缓存** —— 手机上改完前端如果没变化，大概率是浏览器缓存，URL 后面加 `?v=时间戳` 强制刷新。
5. **这一版就是「被打断的基线」** —— 如果要在这版上继续做，请先明确：是继续走纯前端 + localStorage，还是像 V2 那样接后端。这是两条完全不同的路。
